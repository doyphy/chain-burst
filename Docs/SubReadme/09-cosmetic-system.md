## 9 의상 시스템

### 9.1 모듈러 메시 컴포넌트

<img src="../img/Cosmetic/모듈러메시컴포넌트.png" width="750">

**모듈러 메시 컴포넌트에서 본체 메시에 붙일 메시 컴포넌트를 생성하고 팔로우 함.**

- 원하는 만큼 메시를 생성하고 본체 메시를 리더로 삼아 팔로우.
- 본체 메시를 리더 포즈로 연결해서 팔로우 메시 모두 본체 메시의 포즈를 따라가도록 설정.

**바깥에서 쓰는 API**

- `RequestCosmeticPart(Slot, PartID)` : 해당 슬롯(부위)에 파츠ID를 넘기면 카탈로그에서 조회 후 메시를 비동기로 가져와 적용 (각 머신이 조립할 때 사용)
- `GetCurrentCosmeticPartId` / `GetNextCosmeticPartId` / `GetPreviousCosmeticPartId` : 지금 입은 파츠와 다음 · 이전 파츠 태그 조회 (로비 UI 화살표 순회)
- `SetCosmeticForSlot(Slot, Mesh)` 는 로드가 끝난 메시를 슬롯에 끼우는 저수준 함수 - 카탈로그 검증과 복제를 거치지 않으므로 바깥에서 쓰지 않음

### 9.3 의상 교체 경로

<img src="../img/Cosmetic/의상교체경로.png" width="750">

**한 머신 안에서 파츠 태그가 메시로 바뀌는 과정 (`RequestCosmeticPart`)**

- 받은 태그는 셋으로 갈림 - 빈 태그는 선택 안 함(기본 의상 유지), `Item.Cosmetic.None` 은 벗기(즉시 반영), 그 외 파츠 태그만 메시로 바꿈.
- 파츠 태그는 카탈로그 조회 → 비동기 로드 → 마지막 요청과 대조 → 메시 교체 순서로 처리. 로드 중에 다른 요청이 오면 늦게 끝난 이전 결과는 버림.
- UI 는 이 함수를 직접 부르지 않음 - 직접 부르면 그 머신에서만 바뀌고 다른 플레이어에게 보이지 않음. 교체 요청은 9.4 의 컨트롤러 경로(`Server_RequestCosmeticPart`)로 보냄.

### 9.4 의상 복제 경로

<img src="../img/Cosmetic/의상복제경로.png" width="750">

**CB Player State 의 슬롯별 파츠 태그만 복제함.**

- 복제는 최대한 가볍게, 무거운 작업은 로컬에서 읽고 처리.

**의상 복제 경로에 관여하는 클래스 3가지**

- `CB Chaser Controller` : 플레이어의 요청을 받고 검증. (**진입점**)
- `CB Player State` : 플레이어가 요청한 파츠 태그를 관리하고 적용 요청함. (**관리자**)
- `CB Modular Mesh Component` : `CB Player State` 에게 요청 받으면 적용. (**작업자**)
